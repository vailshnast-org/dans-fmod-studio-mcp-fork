# 26. Scripting API Reference

This chapter provides a reference for FMOD Studio's scripting API, and assumes some basic knowledge of programming concepts and JavaScript. For more information about running scripts, and for example scripts, see the Scripting chapter.

The Javascript API available is split over the following modules:

- Globals

- Menu

- Project

- Project.Entity

- Project.ManagedObject

- Project.Model

- Project.Model.Asset

- Project.Model.AutomatableObject

- Project.Model.AutomationCurve

- Project.Model.Automator

- Project.Model.Bank

- Project.Model.Event

- Project.Model.Folder

- Project.Model.MixerEffect

- Project.Model.MixerStrip

- Project.Model.Modulator

- Project.Model.Parameter

- Project.Model.Sound

- Project.Model.Track

- Project.Model.Triggerable

- Project.Workspace

- System

- UI

- Window
